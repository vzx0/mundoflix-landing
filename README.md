# MundoFlix — Landing page

Landing page estática (HTML/CSS/JS em um único arquivo) para o plano vitalício MundoFlix.

- `index.html` — a página completa
- `assets/` — logo e imagens locais
- `baixar-assets.ps1` — baixa pôsteres, fotos e logos externos para `assets/` antes de publicar

## Rodar localmente

```bash
npx -y serve@14.2.4 . -l 5173
```
